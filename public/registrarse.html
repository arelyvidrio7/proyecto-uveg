Términos y Condiciones

El uso de esta aplicación está permitido únicamente para fines académicos y personales. El usuario se compromete a proporcionar información veraz y a no realizar un uso indebido de la plataforma. La aplicación no se hace responsable por fallos técnicos, interrupciones del servicio o uso incorrecto de la información. Al registrarse, el usuario acepta estas condiciones y reconoce las limitaciones de responsabilidad establecidas.

Aviso de Privacidad

Esta aplicación recolecta datos personales como nombre, correo electrónico y fecha de nacimiento con el propósito de gestionar el registro y acceso de usuarios. La información se utiliza únicamente para fines académicos y administrativos, aplicando medidas de protección como conexión segura (HTTPS) y control de acceso restringido. Tus datos no serán compartidos con terceros sin tu consentimiento.
