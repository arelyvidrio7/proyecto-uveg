## Framework principal
- Express.js v5.3.0
## Dependencias adicionales
- node.js v24.18.0
- mysql2 v3.24.5
- dotenv v18.0.7

## Pasos de instalación
1. Instalar Node.js desde https://nodejs.org
2. Clonar el proyecto: `git clone https://github.com/arelyvidrio7/proyecto-uveg`
3. Entrar al directorio: `cd miapp`
4. Ejecutar `npm install`
5. Configurar archivo `.env` con credenciales de MySQL
6. Ejecutar `node server.js`
